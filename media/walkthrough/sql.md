# Run SQL

- Open **New SQL Scratchpad**, put the cursor inside a statement and press **Ctrl+Enter**.
- Results open in a grid: click a header to sort, type to filter, export to CSV.
- Type `ibmi-` in an SQL file for ready-made IBM i Services queries (jobs, job log, locks, PTFs…).
- `DELETE`/`UPDATE` without `WHERE`, `DROP` and `TRUNCATE` ask for confirmation first.
