# Compile

Press **Ctrl+Alt+C** (Cmd+Alt+C on Mac) or click the rocket icon in the editor title.

- Vanthrex picks the compile command from the member type (RPGLE → CRTBNDRPG, SQLRPGLE → CRTSQLRPGI, CLLE → CRTBNDCL…).
- When several commands fit, you choose once and Vanthrex remembers it. Use **Compile With…** to choose again.
- Errors from the compiler events file appear inline and in the Problems panel.
- Change or add commands in Settings → *Vanthrex: Compile Actions*.
