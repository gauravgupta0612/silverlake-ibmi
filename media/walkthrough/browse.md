# Browse and edit

- **Libraries & Source** shows your library list. Expand a library to see its *Source files* and *Objects*.
- Click a member to open it. Saving (Ctrl+S) writes it straight back to the IBM i.
- Use the **search** icon to find a member by name (wildcards with `*`) across the library list.
- Right-click a source file to add a member. RPG and CL members start from a ready-to-compile template.
- **IFS Browser** works the same way for stream files.
