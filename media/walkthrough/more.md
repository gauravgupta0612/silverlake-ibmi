# Monitor and explore

- **System Dashboard**: the dashboard icon on the *Connections* view, or the quick menu (Ctrl+Alt+I).
- **Active Jobs** and **Messages** views in the Vanthrex sidebar. Messages waiting for an answer have a **?** icon: click the reply button.
- **Search objects** (Ctrl+Alt+O) and **search source code** (Ctrl+Alt+F).
- Right-click a file object → **Edit Table Data**; right-click any object → **Where Used**.
- In RPG: **F12** go to definition, **Shift+F12** references, **F2** rename.
- Right-click inside a member → **Show Local History** or **Compare with Copy on IBM i**.
